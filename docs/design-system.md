# Codex Proofline design direction — Forensic Oscilloscope

## Product feeling

Proofline is an audit instrument. It should feel precise, slightly severe, and alive to missing evidence—not like a celebratory project dashboard.

## Visual grammar

- Near-black grid field and phosphor green establish an inspection environment.
- Each evidence state owns one signal color; these colors retain their semantic meaning everywhere.
- Criteria and proof cards form a visible circuit from claim to receipt.
- Glows are reserved for active inspection, never decorative success theater.
- Goal Delta reserves red for the revision fault, amber for stale evidence, phosphor green for dependency paths that remain usable, and violet for removed contract surface.

## Signature interaction

**Gap Tour** walks through the actual non-verified proof cards, one by one. Each stop raises the evidence line, exposes its stored status and reason, and dims unrelated receipts. `G` advances; `Escape` exits.

**Goal Delta** is a second instrument mode, not another dashboard. A split revision redline shows prior and target contract strata around a visible fault. Changed items emit an evidence shockwave only into rows carrying their explicit dependency ID. **Trace impact** (or `D`) isolates one fault and the exact receipts it reaches; `Escape` restores the full section.

## Guardrails

- The tour never promotes missing, stale, declared-only, or failed evidence.
- Local receipts remain tamper-evident records, not cryptographic attestations.
- Screenshot and environment claims retain their explicit evidence ceilings.
- Added, removed, changed, and unchanged are contract verdicts only; evidence remains limited to the five Proofline states.
- No line animates or changes state because it was selected. Trace mode changes emphasis only.

## Acceptance

A reviewer can traverse every release gap without scanning the full report and can see the exact stored reason for each gap.

For Goal Delta, a reviewer can identify the contract edit, affected evidence, isolated evidence, and exact next observation within ten seconds of opening the report.
